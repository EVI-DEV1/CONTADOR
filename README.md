⬢ *Contador*
---

Aplicação simples de manipulação de números com JavaScript

Projeto desenvolvido com JavaScript, HTML e CSS para simular um contador interativo.
A aplicação permite aumentar, diminuir e resetar valores, reforçando conceitos de lógica de programação e manipulação do DOM.


---

⬡ *Propósito*

Praticar lógica de programação com JavaScript

Entender manipulação do DOM

Trabalhar eventos de clique

Criar uma interface simples e funcional

Reforçar conceitos básicos de front-end



---

⬡ *Funcionalidades*

Incrementar valor do contador

Decrementar valor do contador

Resetar contador para zero

Atualização dinâmica na interface

Interface simples e responsiva
